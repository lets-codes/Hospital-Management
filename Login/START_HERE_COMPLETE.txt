🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

❌ MySQL Connection Error:
   → Ensure MySQL service is running (Services.msc)
   → Check MySQL is listening on localhost:3306
   → Verify 'root' user has no password (or update in code)

❌ Flask not starting:
   → Check if port 5000 is already in use
   → Try: netstat -ano | findstr :5000
   → Kill process: taskkill /PID <PID> /F
   → Restart Flask server: python server_python.py

❌ "Module not found" error:
   → Reinstall packages:
   pip install flask==3.1.2 flask-cors==6.0.2 mysql-connector-python==9.6.0 bcrypt==5.0.0

❌ Database not created:
   → Run setup script: python setup_complete_hospital_db.py
   → Check MySQL is running and connected

❌ "404 Page not found":
   → Ensure Flask server is running on http://localhost:5000
   → Check file names are correct (case-sensitive on Linux)
   → Verify server is running in correct directory
