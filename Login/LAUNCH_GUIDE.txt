🚀 HOW TO START THE WEBSITE
───────────────────────────────────────────────────────────────────────────────

STEP 1: Make sure the Flask server is running
   Command: python server_python.py
   Output: * Running on http://127.0.0.1:5000/ (Keep this open)

STEP 2: Make sure MySQL is running
   Port: 3306
   Database: deepanshu
   User: root
   Password: (default/your password)

STEP 3: Open your browser and visit:
   http://localhost:5000/index.html
   OR
   http://localhost:5000/hospital_landing.html

✓ You will see the professional hospital landing page!

🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Q: Server not starting?
A: Make sure Python is installed and Flask is installed (pip install flask)

Q: Database connection error?
A: Verify MySQL is running and "deepanshu" database exists

Q: Website not loading?
A: Check that server_python.py is running in the terminal

Q: Login not working?
A: Check MySQL is running and database tables are created

Q: How to reset database?
A: Run: python setup_complete_hospital_db.py
