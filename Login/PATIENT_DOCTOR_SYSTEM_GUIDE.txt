✅ DUAL-ROLE SYSTEM
   • Patient Portal - Book appointments, view records, manage health

✅ PATIENT FEATURES
   📅 Appointment Booking - Select doctors and time slots

   • lab_tests (laboratory test records)
   • patient_illness_history (disease tracking)
   • doctor_patient_relationship (patient-doctor mapping)

📊 DATABASE SCHEMA OVERVIEW
═════════════════════════════════════════════════════════════════════════════════

LOGIN TABLE (Users):
   • id, full_name, email, phone, password
   • role (patient/doctor/admin)
   • For Doctors: specialization, license_number, experience_years, consultation_fee
   • Timestamps: created_at, updated_at

APPOINTMENTS TABLE:
   • Links patient to doctor
   • appointment_date, appointment_time
   • reason_for_visit, symptoms
   • status (scheduled/completed/cancelled)
   • consultation_type

PATIENT_MEDICAL_RECORDS TABLE:
   • diagnosis, symptoms, prescription
   • vital signs (blood_pressure, temperature, heart_rate, weight, height, bmi)
   • allergies, chronic_conditions, previous_surgeries
   • Links to appointment and doctor

PRESCRIPTIONS TABLE:
   • medicine_name, dosage, frequency, duration
   • instructions, side_effects, contraindications
   • status (active/expired/completed)
   • Links to patient, doctor, appointment

PATIENT_ILLNESS_HISTORY TABLE:
   • disease_name, onset_date, resolution_date
   • severity, status, treatment_type
   • medications_used, hospitalization_required

LAB_TESTS TABLE:
   • test_name, test_code, test_date
   • result_value, result_unit, reference_range
   • interpretation (normal/abnormal/critical)

DOCTOR_SCHEDULE TABLE:
   • day_of_week, start_time, end_time
   • lunch_break_times, max_appointments

DOCTOR_PATIENT_RELATIONSHIP TABLE:
   • Links doctor to patients
   • is_primary flag, relationship_since date

🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Database connection error"
SOLUTION:
   ✓ Ensure MySQL is running
   ✓ Check username/password in code
   ✓ Verify database "deepanshu" exists

PROBLEM: Server won't start
SOLUTION:
   ✓ Make sure Python 3.x is installed
   ✓ Install Flask: pip install flask
   ✓ Install flask-cors: pip install flask-cors
   ✓ Kill any process using port 5000

PROBLEM: "Port 5000 already in use"
SOLUTION:
   ✓ Find PID using port: netstat -ano | findstr :5000
   ✓ Kill process: taskkill /PID <PID> /F
   ✓ Or change port in server code

PROBLEM: Login redirects to wrong dashboard
SOLUTION:
   ✓ Check user.role in browser console
   ✓ Verify role in database
   ✓ Clear localStorage and try again

PROBLEM: Can't access patient/doctor features
SOLUTION:
   ✓ Make sure logged in with correct role
   ✓ Patient account needed for patient features
   ✓ Doctor account needed for doctor features
   ✓ Check browser console for errors

PROBLEM: Appointments not saving
SOLUTION:
   ✓ Ensure all fields filled
   ✓ Date must be future date
   ✓ Check database connection
   ✓ Look at browser console for error details
