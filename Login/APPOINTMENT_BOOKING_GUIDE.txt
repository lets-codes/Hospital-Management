📝 DATABASE TABLES INVOLVED
═════════════════════════════════════════════════════════════════════════════════

APPOINTMENTS TABLE:
   id                    - Unique ID
   patient_id            - References login table
   doctor_id             - References login table
   appointment_date      - Date (YYYY-MM-DD)
   appointment_time      - Time (HH:MM)
   reason_for_visit      - Text description
   consultation_type     - in-person/video-call/phone
   status                - scheduled/completed/cancelled
   created_at            - Timestamp

PRESCRIPTIONS TABLE:
   id                    - Unique ID
   appointment_id        - References appointments
   patient_id            - References login
   doctor_id             - References login
   medicine_name         - String
   dosage                - String (e.g., 500mg)
   frequency             - String (e.g., Twice a day)
   duration              - String (e.g., 7 days)
   instructions          - Additional notes
   prescription_date     - Date created
   expiry_date           - Date expires (30 days from creation)
   status                - active/inactive

PATIENT_MEDICAL_RECORDS TABLE:
   id                    - Unique ID
   patient_id            - References login
   doctor_id             - References login
   appointment_id        - References appointments
   symptoms              - Text
   diagnosis             - Text
   record_date           - Timestamp

❓ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "No doctors available" in dropdown
SOLUTION:
   1. Make sure at least one doctor account is created
   2. Check if doctor role is set correctly in database
   3. Query: SELECT * FROM login WHERE role = 'doctor';

PROBLEM: Appointment not appearing in doctor's list
SOLUTION:
   1. Check appointment date/time are valid
   2. Verify patient and doctor IDs are correct
   3. Check database: SELECT * FROM appointments;
   4. Restart server if needed

PROBLEM: "Patient not found" or "Doctor not found" error
SOLUTION:
   1. Make sure both accounts are created
   2. Check patient_id and doctor_id match database IDs
   3. Try creating new test accounts

PROBLEM: Consultation form not showing patient details
SOLUTION:
   1. Make sure patient selected in dropdown
   2. Try refreshing page
   3. Check browser console for errors (F12 → Console)
