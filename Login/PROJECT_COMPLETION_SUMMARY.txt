SYSTEM ARCHITECTURE
================================================================================

Database (MySQL):
├── login table (users with roles)
├── medicines table (inventory)
└── restock_requests table (communication)
    ├── Tracks requests from pharmacist
    ├── Records approval/rejection by admin
    ├── Stores feedback/reasons
    └── Maintains complete audit trail

Backend (Flask):
├── Role-based access control
├── Request validation
├── Inventory auto-update logic
├── Error handling
└── Data persistence

Frontend (HTML/CSS/JavaScript):
├── Pharmacist Portal
│  ├── Medicine inventory display
│  ├── Restock request submission
│  └── Request status tracking
└── Admin Portal
   ├── Request management
   ├── Approval/rejection workflow
   └── Inventory overview

Communication:
├── REST API endpoints
├── JSON request/response
├── Database as single source of truth
└── Atomic transactions for data consistency
