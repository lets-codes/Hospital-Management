2. OPEN IN BROWSER
   http://localhost:5000/hospital_landing.html

3. SIGN UP A NEW ACCOUNT
   a) Click "Sign Up"
   b) Choose role: Patient or Doctor
   c) Enter details:
      - Full Name
      - Email (must be unique)
      - Phone Number
      - Password (minimum 6 characters)
      - If Doctor: Add specialization, license, experience, fee
   d) Click "Sign Up"
   e) Redirected to login page

4. LOGIN TO YOUR ACCOUNT
   a) Click "Login" or use login.html directly
   b) Enter email and password
   c) Click "Sign In"
   d) Redirected to appropriate dashboard

5. FORGOT PASSWORD
   a) Click "Forgot password?" on login page
   b) Enter your email address
   c) System generates temporary password
   d) Copy temporary password
   e) Enter temporary password and new password
   f) Click "Update Password"
   g) Redirected to login page

❓ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Connection error. Make sure the server is running"
SOLUTION: 
  1. Check if server is running: python server_patient_doctor.py
  2. Verify port 5000 is not in use
  3. Check firewall settings

PROBLEM: "Email already registered"
SOLUTION: Use a different email or delete the user from database:
  DELETE FROM login WHERE email = 'example@email.com';

PROBLEM: "Invalid email or password"
SOLUTION:
  1. Check email spelling (case-insensitive)
  2. Verify password is at least 6 characters
  3. Ensure caps lock is off

PROBLEM: "Temporary password not working"
SOLUTION:
  1. Temporary password is case-sensitive
  2. Make sure you copied it correctly
  3. Request a new reset if needed


🔧 API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════════

POST /signup
  Request: { role, fullname, email, phone, password, [doctor fields] }
  Response: { success, message, user_id, role }

POST /login
  Request: { email, password }
  Response: { success, message, user: { id, full_name, email, role, phone } }

POST /forgot-password
  Request: { email }
  Response: { success, message, temp_password }

POST /reset-password
  Request: { email, temp_password, new_password }
  Response: { success, message }
