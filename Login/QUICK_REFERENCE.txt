📊 DATABASE QUICK REFERENCE
═════════════════════════════════════════════════════════════════════════════════

DATABASE NAME: deepanshu

8 TABLES:

1. LOGIN (User Accounts)
   • id, full_name, email, phone, password, role
   • For doctors: specialization, license_number, experience_years, consultation_fee

2. APPOINTMENTS (Bookings)
   • id, patient_id, doctor_id, appointment_date, appointment_time, reason, status

3. PATIENT_MEDICAL_RECORDS (Health Data)
   • id, patient_id, doctor_id, diagnosis, symptoms, prescription, vital_signs

4. PRESCRIPTIONS (Medicines)
   • id, patient_id, doctor_id, medicine_name, dosage, frequency, duration

5. DOCTOR_SCHEDULE (Working Hours)
   • id, doctor_id, day_of_week, start_time, end_time

6. LAB_TESTS (Test Results)
   • id, patient_id, test_name, test_date, result_value

7. PATIENT_ILLNESS_HISTORY (Disease History)
   • id, patient_id, disease_name, onset_date, resolution_date

8. DOCTOR_PATIENT_RELATIONSHIP (Assignments)
   • id, doctor_id, patient_id, is_primary, relationship_since

🛠️ TROUBLESHOOTING - QUICK FIXES
═════════════════════════════════════════════════════════════════════════════════

ERROR: "MySQL Connection Error"
─────────────────────────────────────────────────────────────────────────────
FIX:
   ✓ Make sure MySQL is running (check Windows Services)
   ✓ Check username/password in code
   ✓ Verify database name is "deepanshu"
   ✓ Run: mysql -u root -p deepanshu

ERROR: "Port 5000 already in use"
─────────────────────────────────────────────────────────────────────────────
FIX:
   ✓ Find PID: netstat -ano | findstr :5000
   ✓ Kill: taskkill /PID <PID> /F
   ✓ Or change port in server_patient_doctor.py (line: app.run(port=5000))

ERROR: "File not found: patient_dashboard.html"
─────────────────────────────────────────────────────────────────────────────
FIX:
   ✓ Make sure all HTML files are in same folder
   ✓ Verify spelling: patient_dashboard.html (not patient-dashboard)
   ✓ File should be in: Login/ folder

ERROR: "Can't find Python"
─────────────────────────────────────────────────────────────────────────────
FIX:
   ✓ Install Python 3.x (python.org)
   ✓ Add Python to PATH
   ✓ Verify: python --version
   ✓ Use: python -m pip install flask

ERROR: "Login redirects to wrong dashboard"
─────────────────────────────────────────────────────────────────────────────
FIX:
   ✓ Check browser console (F12 > Console)
   ✓ Check localStorage: JSON.parse(localStorage.getItem('user'))
   ✓ Verify role in database: SELECT role FROM login WHERE email = 'test@test.com';
