🔐 Login System Setup Guide

Complete step-by-step instructions to get your secure login system running

📋 Prerequisites Checklist

Before starting, make sure you have these installed:

  • Node.js (v12+) - Download
  • MySQL Server (v5.7+) - Download
  • npm (comes with Node.js)
  • A text editor (VS Code recommended)

Step 1️⃣ Create the MySQL Database

1Open MySQL Command Line or Workbench

Start your MySQL server first, then open the command line or GUI.

2Run the database initialization script

Copy and paste the entire SQL code below:

-- Create database CREATE DATABASE IF NOT EXISTS login_system; USE login_system; CREATE TABLE IF NOT EXISTS information_store ( id INT AUTO_INCREMENT PRIMARY KEY, full_name VARCHAR(255) NOT NULL, email VARCHAR(255) NOT NULL UNIQUE, password VARCHAR(255) NOT NULL, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, INDEX idx_email (email) );
✓ If you see "Query OK", the database has been created successfully!

Step 2️⃣ Install Node.js Dependencies

1Open Command Prompt/Terminal

Navigate to the Login folder using:

cd "d:\Storage Box\Computer Input\Visual Studio\Project\Shivani Anand\New folder\Login"

2Install dependencies

Run the following command:

npm install

This will install all required packages (Express, MySQL, bcrypt, etc.)

✓ You should see a "node_modules" folder created and a "package-lock.json" file

Step 3️⃣ Configure Database Connection

1Edit server.js file

Open the server.js file in your text editor and find this section:

const db = mysql.createConnection({ host: 'localhost', user: 'root', // Your MySQL username password: '', // Your MySQL password database: 'login_system' });

Update these values based on your MySQL setup:

Field Default What to Enter
host localhost Usually 'localhost' or '127.0.0.1'
user root Your MySQL username (usually 'root')
password (empty) Your MySQL password (leave empty if no password)
database login_system Keep as 'login_system' (the database you created)
💡 Pro Tip: If you set a password for MySQL, place it in the password field: password: 'yourpassword'

Step 4️⃣ Start the Server

1Run the Node.js server

In the same command prompt, type:

npm start

2Verify server is running

If successful, you should see:

Connected to SQL Database Server running on port 3000
✓ The server is now running on http://localhost:3000

Step 5️⃣ Access the Application

1Open your web browser

2Visit these URLs:

Page URL
Sign Up (Create Account) http://localhost:3000/signup.html
Login http://localhost:3000/login.html
Home (After Login) http://localhost:3000/home.html

🐛 Troubleshooting

❌ "Cannot GET /signup.html"

Solution: Make sure the server is running. Use npm start if you stopped it.

❌ "Connected to SQL Database" not showing

Solution: Check if MySQL is running and your credentials are correct in server.js. You might need to:

  • Start MySQL server
  • Check your username and password
  • Verify the database name is 'login_system'

❌ "npm install" fails

Solution: Delete node_modules folder and package-lock.json, then run npm install again

❌ "Email already registered" when signing up

Solution: The email already exists. Try with a different email address.

❌ "Invalid email or password" when logging in

Solution: Check your credentials. Passwords are case-sensitive. Make sure the account was created first.
