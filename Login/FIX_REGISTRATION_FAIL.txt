- Type: node --version
- Type: npm --version
- You should see version numbers

=====================================================

STEP 2: OPEN COMMAND PROMPT
---------------------------
Press: Windows Key + R
Type: cmd
Press: Enter

=====================================================

STEP 3: NAVIGATE TO LOGIN FOLDER
---------------------------------
Copy and paste this command:
cd "d:\Storage Box\Computer Input\Visual Studio\Project\Shivani Anand\New folder\Login"

Press Enter

=====================================================

STEP 4: INSTALL DEPENDENCIES
-----------------------------
Type this command:
npm install

Wait for it to complete (may take 1-2 minutes)
You should see "added XX packages"

=====================================================

STEP 5: CREATE DATABASE IN MYSQL
---------------------------------
1. Open MySQL Command Line or MySQL Workbench
2. Paste this:

CREATE DATABASE IF NOT EXISTS deepanshu;
USE deepanshu;

CREATE TABLE IF NOT EXISTS login (
    id INT AUTO_INCREMENT PRIMARY KEY,
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_email (email)
);

3. Press Enter
4. You should see "Query OK"

=====================================================

STEP 6: START THE SERVER
------------------------
In Command Prompt (in Login folder), type:

You should see:
- "Connected to SQL Database"

=====================================================

TROUBLESHOOTING:
=====================================================

Problem: "npm is still not recognized"
Solution: 
- Restart Command Prompt completely
- Or restart computer again
- Make sure you installed Node.js correctly

Problem: "npm install gives errors about bcryptjs"
Solution:
- Delete node_modules folder
- Delete package-lock.json
- Run: npm install
- Wait for completion

Problem: "Error registering user" after npm install
Solution:
- Ensure MySQL server is running
- Check database 'deepanshu' and table 'login' exist
- Verify server.js has correct MySQL credentials

Problem: "Cannot GET /signup.html"
Solution:
- Make sure server is running (Step 6)
- Use correct URL: http://localhost:3000/signup.html
- Not: file:///...
