QUICK START - 4 SIMPLE STEPS
==================================

STEP 1: INSTALL PYTHON
======================
1. Go to: https://www.python.org/downloads/
2. Download Python 3.11 or later
3. Run the installer
4. ⭐ IMPORTANT: Check the box "Add Python to PATH"
5. Click "Install Now"
6. Restart your computer

Verify:
- Open Command Prompt
- Type: python --version
- You should see version number (not error)

STEP 3: CREATE MYSQL DATABASE
==============================
1. Open MySQL Command Line or MySQL Workbench
2. Copy and paste ALL of this:

    id INT AUTO_INCREMENT PRIMARY KEY,

TROUBLESHOOTING:
================

Problem: "python is not recognized"
Solution: Reinstall Python and CHECK "Add Python to PATH"

Problem: "pip install failed"
Solution: 
- Close Command Prompt
- Open new Command Prompt
- Try pip install again

Problem: "MySQL connection error"
Solution:
- Make sure MySQL server is running
- Make sure 'deepanshu' database exists
- Check database.sql commands were run

Problem: "Cannot GET /signup.html"
Solution:
- Make sure server_python.py is running
- Check you're using port 5000: http://localhost:5000
- NOT port 3000

Problem: "Registration failed after signup"
Solution:
- Check server output for error messages
- Make sure MySQL database and table exist
- Try a different email address
