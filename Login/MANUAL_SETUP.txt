IMPORTANT: COMPLETE SETUP GUIDE
==================================

Node.js was not properly installed or the system needs a restart.

STEP 1: RESTART YOUR COMPUTER NOW
==================================
This is CRITICAL - the system needs to refresh after Node.js installation.
1. Save everything
2. Restart your computer completely
3. After restart, continue with Step 2

STEP 2: VERIFY NODE.JS IS INSTALLED
====================================
After restart:
1. Press: Windows Key + R
2. Type: cmd
3. Press: Enter

Now in Command Prompt, type:
node -v
npm -v

You should see version numbers like:
v18.13.0
9.2.0

If you see version numbers, continue to Step 3.
If you get error "not recognized", reinstall Node.js from:
https://nodejs.org/

STEP 3: INSTALL NPM PACKAGES
============================
In Command Prompt, copy this command:
cd /d "d:\Storage Box\Computer Input\Visual Studio\Project\Shivani Anand\New folder\Login"

Press Enter.

Then type:
npm install

Wait 1-3 minutes for it to complete.
You should see: "added XX packages"

STEP 4: CREATE MYSQL DATABASE
=============================
1. Open MySQL Command Line or MySQL Workbench
2. If using Command Line, connect first:
   mysql -u root -p
   (Enter your password if you have one)

3. Copy and paste ALL of this:

CREATE DATABASE IF NOT EXISTS deepanshu;
USE deepanshu;

CREATE TABLE IF NOT EXISTS login (
    id INT AUTO_INCREMENT PRIMARY KEY,
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_email (email)
);

Press Enter.

STEP 5: START THE SERVER
========================
In Command Prompt (in Login folder), type:
npm start

You should see:
Connected to SQL Database
Server running on port 3000

LEAVE THIS WINDOW OPEN!
