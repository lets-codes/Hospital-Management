COMMON ISSUES & SOLUTIONS:
─────────────────────────

❌ "Access is Denied" when starting MySQL
→ Run the batch file or PowerShell as Administrator
   Right-click → Run as Administrator

❌ "Port 5000 already in use"
→ The batch file will try to free it automatically
→ Or manually close other applications using it

❌ "Can't connect to MySQL server"
→ MySQL service hasn't started yet
→ Check Services (services.msc) for MySQL80
→ Manually start if needed

❌ "Database connection error" when running Flask
→ Run FIX_CONNECTION_ERROR.py first
→ This will initialize the database properly
