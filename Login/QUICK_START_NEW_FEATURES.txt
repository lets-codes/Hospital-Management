## 🐛 TROUBLESHOOTING

**Q: Tabs not showing?**
A: Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

**Q: Password toggle not working?**
A: Check if JavaScript is enabled in browser

**Q: Data not updating?**
A: Server auto-refreshes every 5 seconds. Wait and refresh manually.

**Q: Logout confirmation not appearing?**
A: Clear cache and reload page

**Q: Settings not saving?**
A: Check if localStorage is enabled (not in private/incognito mode)
