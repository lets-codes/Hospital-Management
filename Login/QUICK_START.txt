================================================================================
🚨 TROUBLESHOOTING
================================================================================

❌ ERROR: "Can't connect to MySQL"
   FIX: 
   1. Ensure MySQL service is running
   2. Check MySQL is listening on localhost:3306
   3. Verify username 'root' has no password set (or update in code)

❌ ERROR: "Module not found (flask, mysql-connector, etc)"
   FIX:
   pip install flask==3.1.2 flask-cors==6.0.2 mysql-connector-python==9.6.0 bcrypt==5.0.0

❌ ERROR: "Port 5000 already in use"
   FIX:
   1. Find process using port 5000: netstat -ano | findstr :5000
   2. Kill process: taskkill /PID <PID> /F
   3. Re-run server.py

❌ ERROR: "Database 'deepanshu' not found"
   FIX:
   1. Run: python setup_database.py
   2. Run: python setup_hospital_db.py
   3. Run: python setup_complete_hospital_db.py

❌ ERROR: "Unknown column 'email' in field list"
   FIX:
   Recreate login table:
   mysql -u root
   USE deepanshu;
   DROP TABLE login;
   CREATE TABLE login (id INT AUTO_INCREMENT PRIMARY KEY, full_name VARCHAR(255), 
   email VARCHAR(255) UNIQUE, password VARCHAR(255), created_at TIMESTAMP 
   DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP 
   ON UPDATE CURRENT_TIMESTAMP, INDEX idx_email (email));
