🔌 API ENDPOINTS (13 Total)
═════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION ENDPOINTS (3):

1. POST /signup - Register New User
   Input: {
      role: 'patient' or 'doctor',
      fullname: string,
      email: string,
      phone: string,
      password: string,
      // If doctor role, also include:
      specialization: string,
      license_number: string,
      experience_years: number,
      consultation_fee: number
   }
   Output: { success: true/false, user_id: number, message: string }

2. POST /login - User Login
   Input: { email: string, password: string }
   Output: { 
      success: true/false,
      user: { id, name, email, role, specialization (if doctor) }
   }

3. POST /logout - User Logout
   Output: { success: true, message: string }


PATIENT ENDPOINTS (4):

1. POST /book-appointment - Book Appointment
   Input: {
      patient_id: number,
      doctor_id: number,
      date: string (YYYY-MM-DD),
      time: string (HH:MM),
      reason: string,
      consultation_type: string
   }
   Output: { success: true/false, appointment_id: number }

2. GET /get-patient-appointments/<patient_id> - Get All Appointments
   Output: [
      {
         id, date, time, doctor_name, specialization,
         reason, status, consultation_type
      }
   ]

3. GET /get-medical-history/<patient_id> - Get Medical History
   Output: {
      illnesses: [...],
      medical_records: [...],
      medications: [...]
   }

4. GET /get-prescriptions/<patient_id> - Get Active Prescriptions
   Output: [
      {
         id, medicine_name, dosage, frequency,
         duration, doctor_name, status, date
      }
   ]


DOCTOR ENDPOINTS (3):

1. POST /add-consultation - Add Consultation & Prescription
   Input: {
      patient_id: number,
      doctor_id: number,
      symptoms: string,
      diagnosis: string,
      medicines: [{name, dosage, frequency, duration, instructions}]
   }
   Output: { success: true/false, consultation_id: number }

2. GET /get-doctor-patients/<doctor_id> - Get All Assigned Patients
   Output: [
      { id, name, age, condition, last_visit, contact }
   ]

3. GET /get-doctor-appointments/<doctor_id> - Get Appointments
   Output: {
      today: [...],
      upcoming: [...]
   }


GENERAL ENDPOINTS (3):

1. GET /get-doctors - Get All Doctors List
   Output: [
      { id, name, specialization, experience, fee, rating }
   ]

2. GET /get-patient-details/<patient_id> - Get Patient Details
   Output: {
      id, name, age, email, phone, medical_history,
      allergies, current_medications, vital_signs
   }

3. GET /health - Health Check
   Output: { status: 'healthy', timestamp: datetime }
