🗄️ DATABASE STRUCTURE
═════════════════════════════════════════════════════════════════════════════════

Database: deepanshu

Tables (8):
   1. login - User accounts (patients, doctors, admins)
   2. appointments - Appointment records
   3. prescriptions - Medicine prescriptions
   4. patient_medical_records - Health records
   5. patient_illness_history - Illness history
   6. doctor_schedule - Doctor availability
   7. doctor_patient_relationship - Patient-doctor links
   8. lab_tests - Lab test records

Key Relationships:
   appointments.patient_id → login.id (patient)
   appointments.doctor_id → login.id (doctor)
   
   prescriptions.patient_id → login.id
   prescriptions.doctor_id → login.id
   prescriptions.appointment_id → appointments.id

    patient_medical_records.patient_id → login.id
   patient_medical_records.doctor_id → login.id
   patient_medical_records.appointment_id → appointments.id


🔌 API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════════

AUTHENTICATION:
   POST /signup - Register new user
   POST /login - Login user
   POST /logout - Logout user
   POST /forgot-password - Request password reset
   POST /reset-password - Complete password reset

APPOINTMENTS:
   POST /book-appointment - Create appointment
   GET /get-patient-appointments/:id - Get patient's appointments
   GET /get-doctor-appointments/:id - Get doctor's appointments
   GET /get-doctors - Get all doctors

CONSULTATIONS:
   POST /add-consultation - Save consultation & prescription
   GET /get-doctor-patients/:id - Get doctor's patients

MEDICAL DATA:
   GET /get-medical-history/:id - Get patient medical history
   GET /get-prescriptions/:id - Get patient prescriptions
   GET /get-patient-details/:id - Get patient complete profile

HEALTH:
   GET /health - Server health check

═════════════════════════════════════════════════════════════════════════════════

✅ Implemented:
   • Password hashing with bcrypt
   • SQL injection prevention (parameterized queries)
   • XSS protection (proper escaping)
   • Email validation
   • Duplicate email prevention
   • Role-based access control
   • Secure password reset process
   • CORS enabled for safe cross-origin requests

✅ Best Practices:
   • Passwords never stored in plain text
   • Unique email addresses enforced
   • Temporary passwords for reset (8 char random)
   • No sensitive data in URL parameters
   • Error messages don't leak information
