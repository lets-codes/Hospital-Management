📞 IF YOU ENCOUNTER ISSUES
═════════════════════════════════════════════════════════════════════════════════

ISSUE: "Connection error" when trying to login/signup
FIX:
   1. Check if server is running (you should see the startup message)
   2. Check server console for error messages
   3. Verify port 5000 is not blocked by firewall
   4. Make sure MySQL is running

ISSUE: "Email already registered"
FIX:
   - Use a different email address, OR
   - Delete the user from database:
     DELETE FROM login WHERE email = 'email@example.com';

ISSUE: "Invalid email or password" on login
FIX:
   - Check email is spelled correctly
   - Password is case-sensitive
   - Ensure no extra spaces in email/password

ISSUE: Temporary password not working in forgot password
FIX:
   - Temporary password is case-sensitive
   - Make sure you copied it exactly
   - Don't add spaces before/after

ISSUE: Can't find website after opening browser
FIX:
   - Make sure server is running (check PowerShell for startup message)
   - Try: http://localhost:5000/login.html directly
   - Or: http://127.0.0.1:5000/hospital_landing.html

💡 QUICK REFERENCE - API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════════

POST /signup
   Input: { role, fullname, email, phone, password, ... }
   Output: { success, message, user_id }

POST /login
   Input: { email, password }
   Output: { success, message, user: {...} }

POST /forgot-password
   Input: { email }
   Output: { success, message, temp_password }

POST /reset-password
   Input: { email, temp_password, new_password }
   Output: { success, message }
