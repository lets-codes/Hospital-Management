───────────────────────────────────────────────────────────────────────────────

Solution:
   ✓ Start MySQL Service:
      - Press Windows Key
      - Type: services.msc
      - Press Enter
      - Find MySQL (e.g., MySQL80)
      - Right-click → Start

───────────────────────────────────────────────────────────────────────────────

Solution:
   ✓ Open another PowerShell
   ✓ Run these commands:

      (Replace XXXX with the number from first command)
