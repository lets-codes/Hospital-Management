## User Flow

### Option 1: Click on Row
```
1. User sees appointment in table
         ↓
2. Hovers over row → Yellow highlight appears
         ↓
3. Clicks anywhere on row
         ↓
4. Confirmation dialog appears:
   "Are you sure you want to delete this appointment?"
         ↓
5a. Clicks "OK" → Appointment is deleted ✓
5b. Clicks "Cancel" → Nothing happens

6. Appointments list reloads
         ↓
7. Success message shows (optional)
```

### Option 2: Click Delete Button
```
1. User sees appointment in table
         ↓
2. Clicks "🗑️ Delete" button
         ↓
3. Confirmation dialog appears:
   "Are you sure you want to delete this appointment?"
         ↓
4a. Clicks "OK" → Appointment is deleted ✓
4b. Clicks "Cancel" → Nothing happens

5. Appointments list reloads
         ↓
6. Success message shows
```

## What Happens Behind the Scenes

### Frontend JavaScript Flow
```
User clicks on row/button
    ↓
cancelAppointment(appointmentId) function called
    ↓
Confirmation dialog shown
    ↓
User confirms
    ↓
fetch() DELETE request sent to backend
    ↓
    DELETE /delete-appointment/123
    Body: { "patient_id": 1 }
    ↓
Backend processes request
    ↓
Response received
    ↓
loadPatientData() called to refresh list
    ↓
Alert shown to user
    ↓
Appointments table updates
```

### Backend Database Flow
```
DELETE request received
    ↓
Verify appointment exists
    ↓
Get appointment's patient_id
    ↓
Verify patient_id matches request
    ↓
Execute: DELETE FROM appointments WHERE id = %s
    ↓
Commit transaction
    ↓
Return success message
    ↓
Frontend receives response
```
