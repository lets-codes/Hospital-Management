────────────────────────────────────────

   4. Click "✅ Save Consultation & Prescription"

STEP 7: View Prescription (As Patient)
──────────────────────────────────────
   1. Log out and log back in as patient
   2. Click "💊 Your Prescriptions" tab

📊 DATABASE STRUCTURE
═════════════════════════════════════════════════════════════════════════════════

APPOINTMENTS TABLE:
   id                  - Unique ID
   patient_id          - Links to patient
   doctor_id           - Links to doctor
   appointment_date    - Date (YYYY-MM-DD)
   appointment_time    - Time (HH:MM)
   reason_for_visit    - Reason text
   consultation_type   - in-person/video-call/phone
   status              - scheduled/completed/cancelled
   created_at          - Timestamp
   updated_at          - Timestamp

PRESCRIPTIONS TABLE:
   id                  - Unique ID
   appointment_id      - Links to appointment
   patient_id          - Links to patient
   doctor_id           - Links to doctor
   medicine_name       - Medicine name
   dosage              - Dosage (e.g., 500mg)
   frequency           - Times per day
   duration            - How long (e.g., 7 days)
   instructions        - Additional notes
   prescription_date   - When prescribed
   expiry_date         - When expires
   status              - active/inactive

PATIENT_MEDICAL_RECORDS TABLE:
   id                  - Unique ID
   patient_id          - Links to patient
   doctor_id           - Links to doctor
   appointment_id      - Links to appointment
   symptoms            - Observed symptoms
   diagnosis           - Doctor's diagnosis
   record_date         - When recorded

❓ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "No doctors available" in dropdown
SOLUTION: Create a doctor account first with valid specialization

PROBLEM: Appointment not showing for doctor
SOLUTION:
   1. Make sure appointment date is correct
   2. Check doctor ID in database
   3. Restart server

PROBLEM: Prescription not appearing for patient
SOLUTION:
   1. Make sure consultation was saved
   2. Check if prescription created in database
   3. Refresh patient dashboard

PROBLEM: "Cannot find appointment" error
SOLUTION:
   1. Check if appointment_date and _time are set correctly
   2. Verify patient and doctor IDs exist
   3. Check server console for errors
