TROUBLESHOOTING - IF YOU STILL GET AN ERROR
════════════════════════════════════════════════════════════════════════════

❌ Error: "MySQL is NOT running"
   Fix: 
   1. Make sure MySQL service is started in Services (services.msc)
   2. If MySQL service doesn't exist, reinstall MySQL
   3. Once started, the server will automatically connect

❌ Error: "Port 5000 is already in use"
   Fix:
   1. Open Command Prompt as Administrator
   2. Run: netstat -ano | findstr ":5000"
   3. Run: taskkill /PID [PID_NUMBER] /F (replace with the PID from step 2)
   4. Try again

❌ Error: "Database connection failed"
   Fix:
   1. Make sure MySQL is running (Step 1 above)
   2. Try these passwords in order: '' (empty), 'root', 'password'
   3. If still failing, check MySQL credentials

❌ Still having issues?
   Try this diagnostic script:
   python FIX_CONNECTION_ERROR.py
